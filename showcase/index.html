SOMA Motion Showcase

13 short clips of NVIDIA MotionBricks SOMA running in this repository's optimized runtime. Tap a video to play. Each one is 1080p H.264 and about 16 seconds long.

Every frame is real model output: 1,256 SOMA generations across 6 model files. Nothing is keyframed or played back from mocap.

Movements

Comparisons

Same input sequence in every panel

How these were made

  • Gameplay input is scripted (direction, gait, actions). The runtime's character controller turns it into target poses, and the SOMA network generates every transition from the 4 poses on screen.
  • The body is NVIDIA's SOMA mesh from the MotionBricks software, skinned to the generated joints and rendered offline with three.js in headless Chromium, then encoded with x264.
  • Comparison panels run the same input sequence with the same random seed; only the labelled setting differs.
  • Green rings under the feet show the model's own foot-contact prediction. Hurdles and the chair are props placed after generation.
